# Консольный набор утилит

**Реализованы команды**:

* `calc`: Команда, реализующая функционал калькулятора 
* `convert`: Команда, реализующая функционал конвертации единиц измерения 
(подробнее по каждой команде далее)

**Дополнительные опции**:

* `--help`: Показать подсказку и выйти.

## `calc`

Команда, реализующая функционал калькулятора с операциями + - * /
Бинарные операции записываются через пробел. (1 + 2)
Операции выполняются по приоритету. (2 + 3 * 4): (3 * 4), потом (12 + 2)
Унарные операции (знак числа) записываются слитно с числом. (-3)
Поддерживаются числа с плавывающей запятой. (3.5)
Вывод:
Число, результат выражения
Или строка с ошибкой.

**Пользование**:

```console
$ calc [OPTIONS] {expr}
```

**Аргументы**:

* `expr`: Выражение  [required]

**Опция**:

* `--help`: Показать подсказку и выйти.

## `convert`

Команда, реализующая функционал конвертации единиц измерения:
Длины: mm, cm, m, km;
Массы: g, kg;
Температуры: c, f, k.
Ввод: значение [единица измерения] [единица измерения после преобразования]
Поддерживаются числа с плавывающей запятой. (273.15)
Вывод:
Число, результат преобразования
Или строка с ошибкой.

**Пользование**:

```console
$ convert [OPTIONS] {value} {unit_from} {unit_to}
```

**Arguments**:

* `value`: Значение  [required]
* `unit_from`: Единица измерения  [required]
* `unit_to`: Единица измерения после преобразования  [required]

**Options**:

* `--help`: Показать подсказку и выйти.

# Установка

В данной лабораторной работе используются стандартные виртальные окружения (https://docs.python.org/3/library/venv.html).
Зависимости лежат в `requirements.txt`.

Должен быть установлен Python>=3.10
* git clone https://github.com/Gimid934/lab01.git
* cd lab01
* python -m venv .venv
* source .venv/Scripts/activate
* pip install -r requirements.txt

**Запуск**
* python -m src.toolkit calc "EXPRESSION"
* python -m src.toolkit convert VALUE --from UNIT --to UNIT
* python -m src.toolkit --help
